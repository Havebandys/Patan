PATÁN V1-PRUEBA

Copia de la V1 estable con la misma aplicación y lógica, pero con la base operativa vacía para pruebas.

Se conservan únicamente los elementos técnicos necesarios para ingresar y operar:
- Usuarios de acceso base (CARLOS y ADM)
- Parámetros/configuración
- Tipos de actividad

Vacío al entregar:
- Trabajos
- Movimientos
- Tareas
- Reuniones
- Histórico/auditoría
- Sugerencias
- Novedades
- Logs de acceso
- Rectificaciones

Además, esta edición no vuelve a cargar los datos demostrativos al iniciar una base vacía.
